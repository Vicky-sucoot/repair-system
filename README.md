# 定期定額

**定期不定額**紀錄：先設定**原始投入金額**，之後每月手動輸入當月投入的日期與金額並按「送出」，每筆投入會**累積**到庫存。網站依網路股價自動計算每筆成交價與股數、**庫存股數**、平均成本、市值、**總損益**、報酬率與年化報酬率（XIRR），並以走勢圖比較資產總值與累計投入。所有金額以新台幣顯示。

支援標的：

| 標的 | 說明 | 幣別 |
|---|---|---|
| 0050 | 元大台灣50 | 新台幣 |
| VOO | Vanguard S&P 500 ETF（複委託） | 美元，依投入日匯率換算 |

預設有兩個投資項目（0050 與 VOO），以「投資項目」下拉選單切換顯示。可在「新增投資項目」輸入台股代號或名稱（例如 `2330`、`台積電`）新增更多項目，每個項目都有「刪除項目」按鈕（至少保留一個）。新增的個股沒有歷史股價，市值以投入時填寫的成交價與最新收盤價（每日更新的台股報價）計算，不計配息與分割。

每個項目分為：

- **基本設定**：投資標的、原始投入日期與金額、原始投入成交價（選填，手動輸入實際成交價後依此換算股數；空白則用當日收盤價）、手續費率、最低手續費、股息預扣稅、整股買進、股息再投入。平時鎖定，按「修改」編輯、「送出」儲存並重新計算。
- **每月投入**：輸入投入日期（預設今天）、金額與成交價（必填）後按「送出」，新增一筆投入紀錄，股數依成交價換算。
- **投入紀錄（累積）**：列出每筆投入的成交價、買進股數、手續費、累計投入與累計庫存；每筆可「修改」（帶回上方表單，按「儲存修改」）或「刪除」。
- **交易紀錄（含配息）**：所有買進、配息與股息再投入明細。

設定與投入紀錄只存在這台裝置瀏覽器的 localStorage，不會上傳；換裝置或清除瀏覽資料會遺失。

## 畫面

單頁式應用程式：畫面最下方的選項列依序為「定期定額、行情、外資動向、新聞情緒、觀察名單」，點選後只顯示該頁；網址會帶上頁面代號（例如 `#news`），並記住上次開啟的頁面。表頭與瀏覽器分頁標題會跟著目前的選項改變。

「行情」頁下方有**自選清單**：先選市場（台股／美股／日股），再輸入代號或名稱加入，顯示最近一個交易日的收盤價、漲跌與漲跌幅，點名稱可開啟 Yahoo 看即時報價。清單只存在這台裝置的瀏覽器。

- **台股**：上市、上櫃股票與 ETF（證交所、櫃買中心 OpenAPI）。
- **美股**：S&P 500 成分股（維基百科）＋常見 ETF 與熱門股（VOO、QQQ、TSM、ASML…）；常見個股可用中文搜尋（蘋果、輝達、特斯拉…）。
- **日股**：日經 225 成分股（日經官方成分股頁，日文名稱）＋常見日股 ETF（1321、1306…）；輸入時不需加 `.T`。
- **美股、日股不顯示價格**：Yahoo Finance、Stooq 等報價來源的 robots.txt 禁止程式自動抓取，因此只提供代號與名稱，點名稱開啟 Yahoo 頁面看報價。
- 資料由每日流程匯出成 `data/quotes.json`；某市場當次下載失敗時沿用上一版資料。

## 股價資料

「最新行情」顯示**加權指數**、**台指期夜盤**（近月、盤後交易時段）、0050、VOO 與美元匯率，點選卡片會在新視窗開啟來源網站（Yahoo 股市、期交所）查看即時報價。

瀏覽器無法直接跨網域讀取這些資料，因此由 GitHub Actions 工作流程 [`update-prices.yml`](.github/workflows/update-prices.yml) 執行 `scripts/fetch-prices.mjs`，寫入 `data/prices.json` 並提交回 `main`：

| 資料 | 來源 | 說明 |
|---|---|---|
| 0050 收盤價與配息 | 臺灣證券交易所（`STOCK_DAY`、`TWT49U`） | robots.txt 允許程式讀取。證交所提供原始價格，程式會偵測分割（例如 2025-06-18 一拆四），把分割前的價格與配息還原成與現價可比較 |
| 加權指數 | 臺灣證券交易所（`MI_5MINS_HIST`） | 同上 |
| 美元兌新台幣 | 臺灣期貨交易所每日外幣參考匯率（`dailyFXRateDown`） | 期交所沒有 robots.txt 限制 |
| 台指期夜盤 | 臺灣期貨交易所（`futDataDown`） | 同上 |
| VOO | Yahoo Finance | 依使用者選擇沿用。Yahoo 的 robots.txt 不允許程式抓取，日後可能被封鎖；失敗時沿用上一版資料 |

- 證交所、期交所的歷史資料第一次需要逐月回補（0050 自 2009 年起，約 15 分鐘），之後每次只抓最近一個月並與既有資料合併。
- 觸發時機：台灣時間週二至週六 07:17（美股收盤、夜盤 05:00 收盤後）與週一至週五 14:17（台股收盤後）、修改 `src/`／抓取腳本並推送到 `main` 時，或在 Actions 頁面手動執行「更新股價資料」。
- 單一標的下載失敗時沿用上一版資料；全部失敗則不更新。
- 網站顯示資料更新時間，超過 4 天未更新會提示資料可能已過期。

## 外資動向與新聞情緒（Python）

網站上的「外資動向」「財經新聞情緒」兩區，由 `analysis/`（Python）每日產生：

1. **數據收集（外資動向）**：抓取證交所 `TWT38U` 與櫃買中心「外資及陸資買賣超彙總表」，存入 SQLite，回補最近 10 個交易日，篩選出：
   - **連續買超**：至今連續 3 天以上買超（`STREAK_MIN_DAYS`）。
   - **單日大買／大賣**：依「買賣超股數 × 最新收盤價」排序，金額 ≥ 5 億元（`BIG_TRADE_VALUE`）標示為大買／大賣。
   - **投信動向**：同樣方式抓取證交所 `TWT44U` 與櫃買中心「投信買賣超彙總表」，產生投信的連續買超、單日大買／大賣（門檻 1 億元，`TRUST_BIG_TRADE_VALUE`），顯示在網站「外資動向」頁的外資表格下方，並寫入 `data/trust.json`。
2. **消息面分析（財經新聞）**：抓取鉅亨網（API）、經濟日報與工商時報（RSS）的當日新聞，只保存標題、連結與 200 字摘要（不轉存全文），抓取前會先檢查 robots.txt。判斷每則新聞是「利多」「利空」或「中性」，並擷取利多／利空關鍵字和相關個股：
   - **Claude（主要分析方式）**：以 `claude-opus-5-5`（可用 `ANTHROPIC_MODEL` 更換）的結構化輸出取得情緒、分數、關鍵字、相關個股與理由，不存在的股票代號會被剔除。啟用後，先前以關鍵字分析的新聞也會重新分析。
   - **關鍵字詞典（備援）**：沒有金鑰、呼叫失敗或被拒答時自動使用，會處理「不看好」之類的否定詞，以及「世界」這類和常用詞同名的股票。
3. **外資動向 Claude 解讀**：Claude 綜合外資連續買超、單日大買／大賣與新聞情緒，產生今日摘要、最多 8 檔重點個股（偏多／偏空／觀察及理由）、題材與風險，顯示在網站「外資動向」區塊上方。只使用當日資料，不預測股價、不提供買賣建議；個股代號必須出現在當日資料中。

4. **綜合評分與建議（今日觀察名單）**：`analysis/recommend.py` 結合外資買賣超與新聞情緒，產生 `data/recommend.json`，顯示在網站最上方「今日觀察名單」：
   - **外資分數 F**（-1～1）＝方向 ×（0.6 × 金額強度 + 0.4 × 連續強度）。金額強度＝√min(1, |買賣超金額| ÷ 20 億元)，5 億元約 0.5；連續強度＝min(連續買／賣超天數, 5) ÷ 5。
   - **新聞分數 N**（-1～1）＝近 3 天提及該股新聞的加權平均情緒（利多 +、利空 −；當天權重 1、前一天 0.6、前兩天 0.36），乘上可信度 min(1, 權重總和 ÷ 1.5)，只有一則新聞時打折。
   - **綜合分數**＝100 ×（0.55 × F + 0.45 × N）。
   - **建議買入**＝外資買超且新聞偏多（F > 0 且 N > 0），依綜合分數由高到低取前 10 檔；**建議賣出／避開**＝外資賣超且新聞偏空，由低到高取前 10 檔。外資與新聞方向相反的個股視為訊號分歧，不列入；只列個股（排除 0 開頭的 ETF／ETN），大盤指數快訊不算個股新聞，同一標題只算一次。
   - 每檔附推薦理由：預設以固定格式列出外資買賣超、連續天數與利多／利空關鍵字；設定 Claude 金鑰後由 Claude 撰寫 40～80 字理由（只使用當日資料、不預測價格）。
   - 觀察名單是籌碼面與消息面的篩選結果，**不是買賣建議，也不保證報酬**；外資資料為前一交易日收盤後數據，新聞情緒可能誤判。

**啟用 Claude**：到 GitHub 儲存庫 **Settings → Secrets and variables → Actions → New repository secret**，名稱填 `ANTHROPIC_API_KEY`，值填 Anthropic API 金鑰。下一次排程（或在 Actions 頁面手動執行「外資動向與新聞情緒」）就會改用 Claude。每天約 2 次新聞分析加 1 次外資解讀，會產生 API 費用；沒有設定金鑰時，網站照常以關鍵字分析運作，只是不顯示 Claude 解讀。

自動執行：GitHub Actions「外資動向與新聞情緒」在台灣時間每天 08:17（以最新新聞搭配前一交易日外資資料）與週一至週五 17:47（當日外資資料公布後）執行，結果寫入 `data/foreign.json`、`data/news.json`、`data/trust.json`、`data/recommend.json`、`data/quotes.json`。

### 本機執行

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m analysis.pipeline            # 抓取、存入 data/market.db、分析並匯出 JSON
uvicorn analysis.api:app --reload      # FastAPI：http://127.0.0.1:8000/docs
streamlit run dashboard/app.py         # Streamlit 儀表板
python -m pytest analysis/tests        # Python 測試
```

API：`GET /api/recommendations`（今日觀察名單，可帶 `top_n`、`big_value`）、`GET /api/foreign`（連續買超、大買、大賣，可帶 `min_days`、`big_value`、`top_n`）、`GET /api/foreign/{代號}`、`GET /api/news?sentiment=利多&stock=2330`、`GET /api/news/stocks`、`POST /api/refresh`（背景重新抓取，僅供本機，未加驗證）。

> 外資資料與新聞版權屬各來源網站；情緒為程式自動判斷，可能誤判，僅供參考，不構成投資建議。

## 目錄結構

- `index.html`、`style.css`：頁面與樣式

- `src/yahoo.js`：解析 Yahoo Finance chart API
- `src/taifex.js`：解析期交所期貨每日行情 CSV（台指期夜盤）
- `src/intel.js`：網站的外資動向、新聞情緒區塊
- `src/tabs.js`：底部選項列與單頁切換

- `analysis/crawlers/global_quotes.py`：美股、日股代號清單（不含價格）
- `analysis/`：Python 爬蟲（`crawlers/`）、SQLite（`db.py`）、外資篩選（`foreign_analysis.py`）、情緒分析（`sentiment.py`）、Claude 外資解讀（`insight.py`）、綜合評分（`recommend.py`）、每日流程（`pipeline.py`）、FastAPI（`api.py`）與測試（`tests/`）
- `dashboard/app.py`：Streamlit 儀表板
- `src/chart.js`：SVG 走勢圖
- `src/app.js`：表單、讀取資料與畫面更新
- `scripts/fetch-prices.mjs`：下載股價並產生 `data/prices.json`
- `tests/`：`node:test` 單元測試
- `sw.js`、`pwa.js`、`manifest.webmanifest`、`icons/`：PWA（網路優先，離線時使用上次快取的網頁與股價）

## 開發

需要 Node.js 20 以上（不需安裝套件）。

```bash
npm test                     # 執行全部測試
node --test tests/dca.test.js  # 執行單一測試檔
npm run fetch-prices         # 下載股價（需能連到 Yahoo Finance）
npm run serve                # 啟動 http://localhost:8000（不可用 file:// 開啟）
```

## 計算規則

- 原始投入於原始投入日期、每筆每月投入於輸入的日期，以當日收盤價買進（原始投入或每月投入有輸入成交價時改用該價格，VOO 以美元計）；遇假日順延到下一個交易日。投入紀錄不必依日期順序輸入，計算時會自動排序。
- 投入日期晚於最新股價日期（例如今天尚未收盤）時列為「待成交」，不計入累計投入，股價更新後自動計入。
- 整股買進時只買得起的整數股數，未用完的金額不扣款；手續費＝成交金額 × 費率，不足最低手續費以最低計。
- 配息依除息日前的持股計算，扣除預扣稅後，可選擇當日再投入或列為現金（計入總報酬）。
- 試算以收盤價估算，與實際成交價可能有差異，僅供參考，不構成投資建議。
