# 報修登記系統
用於登記及管理報修案件。

## 安裝為 PWA

開啟 HTTPS 網站後，Android Chrome 可使用「安裝報修登記」按鈕（瀏覽器允許安裝時顯示）或瀏覽器選單；iPhone／iPad 使用 Safari 的「分享 → 加入主畫面」。安裝後可從主畫面以獨立視窗開啟。圖示、manifest 與 service worker 均使用相對路徑，支援 GitHub Pages 的 `/repair-system/` 子目錄。

第一次須連線開啟，看到「離線說明已備妥」後才具備離線支援。離線重新開啟會顯示操作說明，而不是可送出的表單；已開啟的表單離線時停用送出與重新整理，恢復連線後重新讀取清單。網路顯示在線不代表 Supabase 一定可連線，仍須以送出與讀取的結果提示為準。

只快取離線說明、樣式、manifest 與圖示，不快取報修清單、Supabase API、表單內容、CDN 或文件；不提供背景同步或自動補送。原本開啟畫面中的舊清單僅存在記憶體，離線時會提示不是最新資料。service worker 更新會等舊分頁關閉後啟用，更新快取內容時須增加 `sw.js` 的版本。

本機可執行 `python -m http.server 8000` 後開啟 `http://localhost:8000` 驗證（不可直接使用 `file://`）。手機驗收：安裝並開啟、切至飛航模式後重新開啟確認離線說明、恢復連線後回首頁檢查清單與原有篩選。PWA 不變更資料庫權限，也不新增登入、通知或管理員功能。

## 報修清單篩選

清單上方提供「全部／高／中／低」緊急程度按鈕，預設顯示全部；選中的按鈕以深綠底標示。「高」緊急程度標籤以紅字與淡紅底呈現。

篩選只處理網頁已載入的最近 20 筆，不會額外查詢資料庫，也不代表全部歷史紀錄。沒有符合的資料時會顯示提示；重新整理清單或送出報修後仍保留目前的篩選條件。本次僅更新前端，未變更資料庫、欄位或 `supabase/`。

手機驗收：先確認預設選中「全部」，依序點選「高／中／低」核對清單與選中樣式，再切回「全部」；確認高緊急程度標籤為紅色，且四個按鈕不需橫向捲動即可操作。
