    計算方式

    • 原始投入於開始日（遇假日順延）一次買進；每月於扣款日買進，遇假日順延至下一個交易日，皆以當日收盤價成交。
    • 台股預設整股（零股）買進，未用完的金額不扣款；手續費＝成交金額 × 費率，不足最低手續費以最低計。
    • VOO 以扣款當日美元匯率換算新台幣，預設可買碎股、股息預扣 30% 稅；市值以最新匯率換算。
    • 配息依除息日持股計算；勾選「股息再投入」會於除息日買進，否則列為已領現金，並計入總報酬。
    • 股價與配息來自 Yahoo Finance，每個交易日由 GitHub Actions 自動更新。試算結果僅供參考，不構成投資建議，實際成交以券商對帳單為準。
