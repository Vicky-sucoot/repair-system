計算方式

  • 原始投入於原始投入日期一次買進；每月投入須輸入成交價並以該價格換算股數；原始投入有輸入成交價時亦同（VOO 以美元計），空白則用當日收盤價；每月投入依輸入的日期買進，遇假日順延至下一個交易日，皆以當日收盤價成交。每筆投入會累積到庫存中。
  • 投入日期晚於最新股價日期（例如今天尚未收盤）時列為「待成交」，等股價更新後自動計入。
  • 台股預設整股（零股）買進，未用完的金額不扣款；手續費＝成交金額 × 費率，不足最低手續費以最低計。
  • VOO 以投入當日美元匯率換算新台幣，預設可買碎股、股息預扣 30% 稅；市值以最新匯率換算。
  • 配息依除息日持股計算；勾選「股息再投入」會於除息日買進，否則列為已領現金，並計入總報酬。
  • 今日觀察名單由外資買賣超與新聞情緒自動評分產生，每個交易日更新（台灣時間 08:17、17:47），僅供研究參考，不構成投資建議。
  • 外資動向來自臺灣證券交易所與證券櫃檯買賣中心「外資及陸資買賣超彙總表」，金額以最新收盤價估算；財經新聞來自鉅亨網、經濟日報、工商時報，只顯示標題與摘要。新聞情緒與外資解讀由 Claude AI 分析（未設定金鑰時改用關鍵字詞典），可能有誤，僅供參考，不構成投資建議。
  • 股價、配息與加權指數來自 Yahoo Finance，台指期夜盤（近月、盤後交易時段）來自臺灣期貨交易所；每個交易日由 GitHub Actions 自動更新兩次（台灣時間 07:17 與 14:17），點選行情卡片可開啟來源網站看即時報價。試算結果僅供參考，不構成投資建議，實際成交以券商對帳單為準。
